# Changelog

All notable changes to this project are documented here.

## [Unreleased]

### Added

- Multi-layer background rendering from level JSON (`backgroundLayers`) with per-layer parallax/scale/offset.
- Decor pipeline (`decor`) for non-colliding depth-aware visuals with per-item texture/parallax/layer controls.
- Level manifest support (`public/levels/manifest.json`) with runtime level switching and level metadata overlay.
- New demo map: `public/levels/demo-decor.json`.
- World-space background layers (`"mode": "world"` in `backgroundLayers`): a painted image placed at a fixed world rectangle (or fitted to level bounds) with optional grounded parallax, so platforms can be aligned to painted features. Parallax remains the default mode. Validator and `docs/architecture/level-format.md` updated.
- New demo map `public/levels/demo-pano.json` (pano generated by `scripts/gen_demo_pano.py` from the level's own platform coordinates).
- Level-authoring aids for placing platforms against busy backgrounds (parallax and world-space alike). `G` toggles a world-space grid (orange axes, brighter major lines), `Shift+G` cycles its spacing 1.0 / 0.5 / 0.25, `H` toggles authoring mode: a HUD with mouse world coordinates, snapped coordinates and camera view range, high-contrast platform outlines, dimmed player/particles, and a snap marker. `P` (in authoring mode) copies a platform JSON snippet at the snapped cursor position. Hotkeys are ignored with Ctrl/Meta/Alt held or while a form control is focused. Helpers in `src/lib/authoring.ts` with unit tests; Playwright coverage in `tests/e2e/authoring.spec.ts`.
- Render-only visible-rect culling: `drawScene` skips platforms (textured + debug boxes), decor (parallax-aware), goals, particles and authoring outlines that lie fully outside the camera view plus a 1-unit margin (`src/lib/culling.ts`). Physics/collision and the player sprite are untouched. `K` toggles a cull debug view: the cull rect is shrunk 2 units inside the screen and outlined in magenta, with a `drawn/total` counter HUD. Unit tests in `tests/unit/culling.test.ts`; Playwright coverage in `tests/e2e/culling.spec.ts`.
- ESLint 9 flat config (`eslint.config.js`) and `lint:fix` script.
- Structured documentation hub under `docs/`:
  - `docs/ai/`
  - `docs/plans/`
  - `docs/architecture/`

### Changed

- Camera supports optional vertical follow + Y clamping via per-level camera config.
- Goals are read from WASM getters in the render loop instead of mirrored JS refs.
- README and AI docs now cross-link to the new docs layout.
